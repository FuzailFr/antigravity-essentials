# GitHub Copilot Instructions

- Be concise and actionable. Omit introductions, apologies, and closing pleasantries.
- Provide targeted code changes and patches matching existing project style and types.
- Follow YAGNI: the simplest solution that works. Minimal dependencies and zero bloat.
- Do not add comments explaining self-evident syntax.
- Ensure accessible UI, mobile ergonomics, and complete Open Graph metadata for web endpoints.
- Ensure natural, organic phrasing when communicating in Bahasa Indonesia.
